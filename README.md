# Interactive Excel Dashboard – Online Sales in the USA

## Overview
This project presents an interactive Excel dashboard built using a Kaggle dataset on online sales in the USA. The goal was to transform raw data into meaningful business insights using Excel’s built-in tools.

---

## Objective
To analyze online sales performance and identify key trends in revenue, product categories, customer distribution, and regional performance.

---

## Tools & Techniques
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Power Pivot
- Macros 
- Slicers 
- Conditional Formatting

---

##  Workflow
- Data cleaning and transformation
- Data modeling using Power Pivot
- Dashboard design with interactive elements
- KPI calculation and visualization

##  Key Insights
-  Total Revenue: **$234M**
-  South region generated the highest revenue
-  Mobiles & Tablets were the top-selling category
-  Los Angeles was the top-performing county
-  Sales were evenly distributed across genders
-  December recorded the highest monthly revenue
